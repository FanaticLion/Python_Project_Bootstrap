# PythonProjectBootstrap

Веб-приложение на Flask с простым HTTP сервером для обработки контактов.

## 🚀 Функциональность

### Solution 1: Flask Web Application
- **Главная страница** - отображение товаров
- **Каталог** - просмотр товаров по категориям  
- **Контакты** - форма обратной связи с сохранением в БД
- **Профиль** - страница пользователя
- **База данных** - SQLite с товарами и контактами

### Solution 2: Simple HTTP Server
- **GET запросы** - возвращает страницу "Контакты"
- **POST запросы** - принимает данные формы и выводит в консоль
- **Bootstrap 5** - стилизация через CDN

## 📦 Установка и запуск

### Предварительные требования
- Python 3.8+
- pip или poetry

### Установка зависимостей
```bash
pip install flask


### Запуск Solution 1 (Flask приложение)
python Main.py 
Приложение будет доступно по адресу: http://localhost:8000 

Запуск Solution 2 (HTTP сервер)

cd solution2_httpserver
python simple_server.py

Сервер будет доступен по адресу: http://localhost:8080


### База данных 
Проект использует SQLite базу данных. При первом запуске автоматически:

Создается файл data/app.db

Создаются таблицы contacts и products

Добавляются тестовые товары

📝 API endpoints
Flask приложение (Solution 1)
GET / - главная страница

GET /catalog - каталог товаров

GET /category/<name> - товары по категории

GET /contacts - страница контактов

POST /contacts - обработка формы контактов

GET /product/<id> - страница товара

GET /profile - профиль пользователя

HTTP сервер (Solution 2)
GET / - возвращает страницу contacts.html

POST / - принимает данные формы, выводит в консоль
